# Foldable mobile stand

a simple and portable mobile stand designed using **autodesk fusion 360**. the stand is made with separate parts and a folding mechanism, making it easy to open, close and carry.
Printables:- https://www.printables.com/model/1924449-foldable_mobile_stand

## About the project

the foldable mobile stand is a cad design project created to provide a comfortable way to hold a smartphone while watching videos, attending online classes, browsing or making video calls.

the main idea is to create a stand that can support a mobile phone at an adjustable viewing angle and fold flat when not in use. the design includes a strong base, a back support, connecting pins and an angle support mechanism.

the complete model was designed in fusion 360 by creating each part separately and bringing them together into one assembly.

## Project objectives

- design a simple and useful mobile stand.
- create separate parts using fusion 360.
- add a folding mechanism to make the stand portable.
- provide proper support to hold a smartphone.
- include space for connecting a charging cable.
- prepare the model for possible 3d printing.

## Main features

- **foldable design:** can be folded to make it easier to store and carry.
- **phone support:** a back plate holds the mobile phone.
- **front holding lip:** helps prevent the phone from slipping.
- **charging cable opening:** provides space for connecting a charging cable.
- **hinge connections:** allow the main parts to move.
- **angle support:** helps support the back plate at different positions.
- **rubber pad spaces:** provide space for adding grip pads underneath the base.

## parts used

the model consists of five main parts:

| part name | purpose |
|---|---|
| base | supports the complete stand |
| back support | holds the mobile phone |
| hinge pin | connects the base and back support |
| angle support | supports the back plate at an angle |
| strut pin | connects the angle support to the back support |

## software used

- autodesk fusion 360

## design process

the project was completed in six phases:

**phase 1 – base design**  
created the main base with rounded corners, hinge sections and spaces for rubber pads.

**phase 2 – back support design**  
designed the back plate with a front lip, charging cable opening and hinge features.

**phase 3 – hinge connection**  
worked on the pin holes and alignment between the base and back support.

**phase 4 – folding support mechanism**  
created the angle support and connecting pins for the folding arrangement.

**phase 5 – assembly**  
brought the individual parts together and worked on their positions and movement.

**phase 6 – final design**  
made the final adjustments, applied colours and prepared the completed cad model.

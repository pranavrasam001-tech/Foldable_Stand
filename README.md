# Foldable Mobile Stand

a simple and portable mobile stand designed using **Autodesk Fusion 360**. it features a folding mechanism, making it easy to open when required and fold flat for convenient storage and carrying.

**Project Link:** https://www.printables.com/model/1924449-foldable_mobile_stand

## About the Project

the foldable mobile stand is a CAD design project created to provide a comfortable way to use a smartphone while watching videos, attending online classes, browsing or making video calls.

the main aim was to create something simple, useful and easy to carry. the stand has a base, back support and a folding mechanism that holds the phone at a comfortable viewing angle. each part was designed separately in fusion 360 and then assembled to form the complete model.

## Project Objectives

- to design a simple and useful mobile stand.
- to create separate parts using fusion 360.
- to include a folding mechanism for easy storage.
- to provide proper support for a mobile phone.
- to leave space for connecting a charging cable.
- to make the design suitable for 3D printing.

## Main Features

- **Foldable Design:** folds flat when not in use, making it easy to carry.
- **Phone Support:** holds the mobile phone in position.
- **Front Lip:** helps prevent the phone from slipping.
- **Charging Space:** allows a charging cable to be connected.
- **Hinge Connection:** allows the main parts to move while folding.
- **Angle Support:** helps keep the back plate in position.
- **Rubber Pad Spaces:** provide room for adding grip pads underneath the base.

## Parts Used

| Part Name | Purpose |
|---|---|
| Base | supports the complete stand |
| Back Support | holds the mobile phone |
| Hinge Pin | connects the base and back support |
| Angle Support | supports the back plate |
| Strut Pin | connects the angle support to the back support |

## Software and Material

- **Autodesk Fusion 360** – used for designing and assembling the parts.
- **PLA Filament** – intended material for 3D printing.

## Design Process

the project was completed in six phases:

**Phase 1 – Base Design**  
started by creating the base with rounded corners, hinge sections and spaces for rubber pads.

**Phase 2 – Back Support Design**  
designed the back plate and added a small lip to hold the phone. a space for the charging cable was also included.

**Phase 3 – Hinge Connection**  
worked on the pin holes and adjusted the alignment between the base and back support.

**Phase 4 – Folding Support Mechanism**  
designed the angle support and connecting pins required for the folding arrangement.

**Phase 5 – Assembly**  
brought all the individual parts together and adjusted their positions to form the complete stand.

**Phase 6 – Final Design**  
made the final adjustments, applied colours and prepared the completed CAD model.

## 3D Printing Instructions

the parts are intended to be printed using PLA filament. the following steps can be used to prepare them for printing:

1. download the STL files.
2. open them in a 3D printing slicer.
3. select PLA as the printing material.
4. arrange each part properly on the print bed.
5. choose suitable layer height and infill settings.
6. add supports wherever required.
7. slice the parts and check the estimated filament usage.
8. export the G-code and begin printing.

## Assembly Instructions

once all the parts have been printed, follow these steps:

1. place the base on a flat surface.
2. position the back support between the hinge sections.
3. insert the hinge pin through the aligned holes.
4. connect the angle support to the back support using the strut pin.
5. check that all the parts are properly aligned.
6. gently open and fold the stand to check its movement.
7. place a phone on the stand and check its position.
